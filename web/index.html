почему Rope

Узел, который принадлежит вам.

Your server. Your keys. No foreign cloud.

Не чужое облако

Переписка идёт через ваш VPS. Нет общей очереди «для всех пользователей мира» и нет чужого аккаунта как точки отказа.

Ключи на телефоне

Текст, фото и голос упакованы в конверты на устройстве. Go-релей хранит то, чего не понимает.

Телефон ↔ VPS

Клиент поднимает сервер по SSH. Друзья входят по QR. Сервер связывает устройства, но не читает содержимое.

возможности

Тихий мессенджер, который вы сами держите.

E2EE, groups, voice, WebRTC calls, photos.

Сквозное шифрование

Текст, голос, фото и файлы закрываются на устройстве. Rust-ядро держит ключи; сервер хранит непрозрачные конверты.

Группы

Общие чаты на вашем сервере. Состав группы меняется на реле; содержимое по-прежнему попарно зашифровано.

Голосовые

Зажали — говорите. Запись уходит как зашифрованный объект, без облачной распознавалки.

Звонки WebRTC

Аудио по DTLS-SRTP. Если дырку в NAT не пробить, тот же VPS даёт TURN и только ретранслирует шифротекст.

Фото и файлы

Вложения режутся и шифруются на телефоне. На диске сервера лежат только объекты с истечением срока.

как начать

Сервер заводится с телефона. Люди входят по QR.

Create a server, then join with a QR invite.

  1. 01

    Создайте сервер

    В приложении вводите SSH к Ubuntu/Debian VPS. Rope заливает бинарь и install.sh: TLS, владелец, systemd. Первый вход с setup-токеном становится хозяином.

  2. 02

    Пригласите по QR

    Одноразовая ссылка несёт адрес, id сервера и отпечаток TLS. Чужой endpoint с подменённым сертификатом приложение отвергнет.

  3. 03

    Переписывайтесь

    Чаты идут по WSS. История живёт на устройствах. Сервер — почтовый ящик для шифротекста, не читатель переписки.

самохост

Один скрипт на Ubuntu.

Phone → SSH → VPS, or the same installer from a machine.

С телефона VPS поднимается из приложения. С машины — тот же installer:

sudo ./deployment/scripts/install.sh \
  --binary ./rope-server-linux-amd64 \
  --host YOUR.IP \
  --port 8443

Первый bootstrap с SETUP_TOKEN становится владельцем. --upgrade меняет бинарник и coturn, базу оставляет. --reinstall — чистый узел и новый токен.
